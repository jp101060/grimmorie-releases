# Grimmorie — builds

Este repositório só guarda as versões do jogo para o **Grimmorie Launcher**.

1. Baixe o `GrimmorieLauncher.exe` na release **Grimmorie Launcher**.
2. Abra-o: ele instala o jogo e baixa as atualizações sozinho.

O Windows pode avisar que o app não é reconhecido (ele não é assinado): clique em
**Mais informações → Executar assim mesmo**.
